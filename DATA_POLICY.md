# Data and source policy

This repository contains reusable marking logic only.

Do not commit:

- HSC examination papers or marking guidelines;
- syllabus PDFs or converted syllabus text;
- textbooks, commercial study notes, school resources, or answer banks;
- student names, responses, marks, identifiers, or assessment records;
- screenshots, OCR output, or extracted text from source documents;
- local file paths, access tokens, credentials, or private links.

Users are responsible for obtaining and using reference materials lawfully. Supply authorised material at runtime or keep it in a private local directory outside the repository.

Examples and tests must be newly written, anonymous, and free of copied source passages.
